Current take

The specifications are the contract. When a skill, a genre card or a page in this library disagrees with them, they win and the other is fixed. They are Markdown files in the repository, outside this library, so they link to GitHub.

The specifications

  • The folio model Read first: documents, links, maps, the journal, genres, packs, the charter and the gate, in one contract.
  • The genre format How a genre card is written: its settings, fields, parts and sections.
  • The checks Every check the gate runs, its settings and its default severity.
  • The folio command Every command the skills call, and what each one changes.
  • The pack format How a pack and a workflow are written.
  • The skill format The shape every skill follows: start, rules, steps, stops, done when.

The shell

  • The shell's components What the shell draws on every page, and the components a page may write.

Current take

folio is built with its own lab pack. Each question it asks of itself gets a locked protocol before anything is measured, and each measurement becomes a result.

One question is answered so far: the gate is fast enough to run before every commit. The chain below is how that answer was reached, and every link in it is a document you can open.

Ask. A question says why it matters, what would settle it, and what would make the library drop it, before any plan to measure.

Lock. A protocol names the one variable, what is held fixed and the decision rules. Once locked, it is frozen: the gate checks it against git.

Measure. Each run becomes a result: a number, its baseline, its bounds and the command that re-derives it. A result is a permanent record.

Answer. The question's answer cites the results by id, and its status moves to answered. A later result can supersede one without editing it.

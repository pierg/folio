Library
A library is a folder holding a folio.yaml charter, a content/ folder of linked documents, an assets/ folder, and the generated indices in .folio/. It can be a project's docs/ folder, a notes folder, or a whole repository.

Why it matters

Everything folio does is scoped to one library: the gate checks one library, the site exports one library, and ids are unique within one library. One project can hold several libraries, and a charter can list others to search alongside its own.

The trap

Reading the library as a website. The pages are plain HTML and Markdown in git, readable with no build step. The site is one view of them, written by export.

Related

Every document in a library has a genre, and readers enter through its maps.

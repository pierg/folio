Genre
A genre is a kind of document, such as a concept, a note or a result. It fixes the document's job, its reader, its voice, its format, where it lives, which metadata it carries, how it may change over time, and which checks it must pass.

Why it matters

An agent writing a document reads its genre's card first, every time. So two documents of one genre read as if one author wrote them, and the gate can check what each genre promises. Voice is never set per document.

The trap

Treating a genre as a template. The skeleton is the smallest part of it. The card also says what the document is for and what it must never do, and most of that is judged by the agent, not checked.

Related

The core has eight genres. A pack adds more, and a library can override a genre or add a variant for a second audience.

Journal
The journal is a library's dated record of what happened and what was decided. Each entry is its own short Markdown file with a date, an optional kind, and the ids of the documents it is about.

Why it matters

Documents say what is true now; the journal says when it changed and why. An entry shows on every document it names, and the shell renders all entries as one timeline that filters by kind, tag, date or document.

The trap

Writing a decision only into the page it changed. The page will be revised again and the reason lost. The decision goes in the journal, about that page.

Related

Every entry is a permanent record, and the only document no map needs to list.

Map
A map is a document that lists other documents in the order to read them, each row with an optional one-line reason to follow it. The maps the charter names as home maps are the library's topics, drawn on its home page.

Why it matters

A library has no folder tree for a reader to browse; folders follow genres, not subjects. Maps are the structure instead. A document can sit on several maps, and a map can list other maps, so one library can have as many front doors as it needs.

The trap

Using tags as structure. Tags are facets for filtering. A reader arriving cold needs an order and a reason, and only a map gives them.

Related

The gate checks that every document except a journal entry is reachable from a map.

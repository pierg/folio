Question a passage on the page

With the library served by folio serve, every page has a Comments button. Select a passage and ask about it: "is this still true?", "say why", "cut this". You can also comment on the whole page. There is no name to type: the server writes as you, your git user name. The comment is saved in a file beside the document and committed on its own. Nothing goes into the page itself.

Where is a comment stored?
In a file beside the document, <name>.annotations.json, committed by the server. The exported site leaves these files out.

Flags wait for you

Some threads were opened by the agent. Where it wrote something its sources did not say, such as its own example or a claim from general knowledge, it left a flag labelled with the kind of addition. A flag asks nothing. It rests until you press one of its two buttons. Keep closes it, and the passage stays. Change asks what to change, and your answer becomes a question the agent picks up.

You do not have to visit every page to find them. The Review page lists every question waiting on the agent and every flag resting for you, newest first, and the home page shows one line counting them.

The agent left a flag on an example and you are happy with it. Does anything have to happen?
No. A flag rests until you act on it. Press Keep when you want it off your Review page.

Ask the agent to go through them

Say "go through my comments". The agent follows the address skill: for each waiting question it edits the document, or declines with a reason, and replies on the thread saying exactly what it did. Nothing is deleted. Each thread shows its state in plain words: waiting, resting, or closed, with how it closed: changed, kept, declined or withdrawn. Once the agent's reply is committed, a changed thread also shows the passage before and after.

  1. Step 1 · You ask

    You select the sentence about the holding folder and ask whether it is still true. The server saves the thread beside the page and commits it on its own. The thread is waiting.

  2. Step 2 · It waits on Review

    The question joins the Review page, under the questions waiting on the agent, and the home page's line counts it. It stays there until it is answered or withdrawn.

  3. Step 3 · You hand it over

    You say "go through my comments". The agent lists every waiting thread and takes them one at a time, on the page each was left on.

  4. Step 4 · The agent answers

    It edits the sentence to match the code, and replies on the thread with what it changed. The thread closes as changed. Had it disagreed, it would have declined with its reason, and closed the thread that way.

  5. Step 5 · You see what changed

    Once the reply is committed, the thread shows the passage before and after, computed from git. You read the answer and the edit side by side, without opening a diff.

If the document is a permanent record, the agent does not edit it. It adds a correction that points back, and the record shows it as a banner. The gate also fails while an open question quotes text that is no longer on its page, so a comment is never silently lost under an edit.

You asked a question about a journal entry. Will the agent edit the entry?
No. A journal entry is permanent. The agent writes a new entry of kind correction about it, which shows on it as a banner.
The agent disagrees with your question and leaves the page as it is. What does the thread show?
Closed, declined, with the agent's reply giving its reason. The thread stays on the page; a closed thread takes a reply and can be reopened.

Ask for a document in plain words

Say what you want: "add a concept for eventual consistency", "write a note on why we pinned the parser", "log that we chose Postgres". The agent matches the request to a genre and confirms it in one line. It asks only when two genres fit equally well.

The core has eight genres. A concept defines one term. A note states one idea with its reason. An entry argues a subject in sections. A guide, like this one, teaches in chapters. A map lists documents in reading order. A project page says where some work stands. A journal entry records an event. A paper is a LaTeX paper with a landing page.

You want to pin down what a term means, so other pages can point to it. Which genre?
A concept. It holds the definition once, and every other mention links to it.

What the agent does to write it

The agent follows the write skill. It reads the genre's card, searches the library so the fact does not get a second home, and creates the document from the genre's skeleton. It writes the title and a one-line description into the metadata, and the body in the genre's voice.

It links every term that has a concept, cites other documents by id, and puts the new document on a map. Where it writes something its sources did not say, such as an example of its own, it leaves a flag on the passage for you to keep or change. Then it runs the gate and commits.

The agent invented an example to make a concept clearer. How will you know?
It leaves a flag on that passage, labelled "worked example". Flags wait for you on the rendered page.

Read it

Ask your agent to serve the library. It runs folio up, and the library opens at http://127.0.0.1:5170/. The home page shows the top-level maps and the latest journal entries. Every page has the same shell: the library on the left, with the maps and every document by genre, a header drawn from the metadata, light and dark themes, search on the / key, a preview when you hover a link, and a panel listing what the page cites and what cites it.

Where does the list of pages that cite this one come from?
The shell generates it from the links. Nobody writes it, so it cannot go stale.

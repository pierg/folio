How to read it

In order, once. It is for someone who has a project and a coding agent, and wants the agent to keep a library of documents beside the code: notes, explanations, records of what was decided and measured.

You need a git repository and an agent that can run commands in it. You do not need to learn the folio command: your agent runs it. Each chapter shows what to ask for, what the agent does in reply, and what you get.

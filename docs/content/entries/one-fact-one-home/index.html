A fact lives in exactly one document, and every other document cites that one by id. A library kept this way can be corrected in one place, and a reader can always follow a claim to where it is held.

Four steps make the case: what a fact's home is, what goes wrong when a fact is copied instead, how much of the rule a machine can check, and how documents about the same thing share it without sharing sentences.

Step one

The rule

A fact is a definition, a measured number or a decision. Its home is the document whose genre holds that kind of fact: a concept for a definition, a result for a number, a journal entry for a decision. Every other page links the home and says what the fact means for its own reader, in its own words.

Step two

Why one home

Two copies of a fact agree on the day they are written. Then one is revised and the other is not, and the library holds two answers with nothing to say which is right. With one home, a correction lands once and reaches every page that cites it.

The rule also makes a library checkable. A number that cites its result can be followed in one click to its evidence and the command that re-derives it, as R-1 shows for the time this library takes to check.

Step three

What is checked and what is judged

Part of the rule is mechanical, and the gate checks it. The rest is judged by the agent, by reading.

The gate checks

  • No two concepts define the same term.
  • With the lab pack on, a number shaped like a measurement cites a result in the same sentence.
  • Every citation resolves to the document it names.

The agent judges

  • A paraphrase of a definition, written as if it were new.
  • A decision restated as if this page made it.
  • A number from another document, given as this page's own.
Why does a concept's definition cite nothing?
So it stays true when a number changes. Results are cited below the definition, never inside it.

Step four

Siblings share ids, never sentences

A journal entry, a report and a paper about the same result each cite the result and reuse its figure. None is generated from another, because each has a different reader. What they share is the id, so they cannot disagree about the number.

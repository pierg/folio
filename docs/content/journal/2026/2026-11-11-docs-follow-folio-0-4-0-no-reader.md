folio 0.4.0 removed reader comments (the comment files beside pages, the folio annotations command, the comment panel, the address skill, the stale-quote check, comments in the charter and folio serve --push) and the To review list, because nobody used them. A flag is now a line in the agent's report to the owner.

The docs follow. The Getting started guide drops its two comment chapters, Reviewing comments and Comments on a deployed library, and is now three chapters; their old addresses redirect to the guide's front page. Your first documents shows a flag as a line in the report. Organising no longer moves comment files or sends open comments to a skill. The home page's loop ends with you reading the site and asking again. Skill, Pack, Library and the folio project page describe six skills. Gate drops its stale-quote example. Using folio describes the three-chapter guide.
